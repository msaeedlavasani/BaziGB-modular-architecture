## بخش ۱ — تصمیمهای عمدی (Intentional Differences)

این موارد عمداً متفاوت یا حذف شده‌اند و **تسک نیستند**:

| مورد | وضعیت |
|---|---|
| ورود با ایمیل/پسورد (`/auth/login`، `/auth/register`) | طبق درخواست کاربر حذف شد — فقط OTP با شماره موبایل |
| تغییر رمز: `PATCH /auth/change-password` | معادل جدید: `PATCH /auth/me/password` (موجود) |
| Match Point و «برد با ۲» | فقط برای نرد و دوز (قانون معماری — عمدی) |
| سیستم مختصات نرد (۲۴ خانه + bar/off جدا) | بازطراحی عمدی روی `GameAdapter` (داخلِ حالت: `board`/`bar`/`off`) |
| موتور شطرنج | موتور سفارشی بهجای chess.js (استقلال پکیج — عمدی) |
| وگاس: ۵۴ کارت، ۶ کازینو، ۸ تاس، ۴ راند، sweep | بازسازی کامل قوانین قدیمی روی انجین جدید ✓ (مطابق درخواست) |
| سایدبار چت قدیمی (ChatSidebar.tsx) | معادل فشردهٔ MUI داخل صفحهٔ /play پیاده شده (پنل «گفتگو») |
